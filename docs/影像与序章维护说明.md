# 影像与序章

本次不包含虚构的藏家或官方摄影作品。正式图库仍为空，测试素材只存在测试脚本内，不会打包到正式网站。

## 添加作品

在 src/collector-gallery-data.ts 中维护 collectorGallery（藏家）或 officialGallery（官方）。

每张图提供：唯一 id、图片地址 src、图片说明 alt、原始宽高 width/height、作者 author、平台 platform、标签 tags、花卉标识 flowers，以及已确认展示授权 authorized。

可选字段：

- publishedAt：真实发布时间，使用统一格式，如 YYYY-MM-DD。
- series：系列名称，用于详情页的“其他系列”推荐。
- groupId：同一次拍摄或投稿的组号，用于“同组影像”。
- postUrl、profileUrl：原帖和创作者主页的 HTTPS 链接。
- description：作品说明。

不填的可选信息不显示。authorized 为 false 的作品不会出现在列表、详情或推荐中。排列按数据顺序稳定追加，不随机洗牌。请填写正确原图尺寸，避免布局偏差。

## 序章

档案默认以无声互动海报打开，完整播放由访客主动选择。切换回海报会停止并移除视频。题字和按钮是网页独立图层，可选择完整显示、只留题字、纯净画面。

当前荷花序章素材沿用网站已有 opening 目录文件；不改动首页首次访问序章。

## 售卖状态

src/opening-sale.ts 的 lotusSale 维护该期售卖状态：

- closed：关仓，即使留有链接也不显示购买。
- open：有效 HTTPS 购买地址才会显示购买入口。
- scheduled：填写带时区的 opensAt，例如 2026-10-01T20:00:00+08:00。该日期仅示例，不是实际开仓安排。

倒计时结束后，有有效链接则显示购买入口；没有链接继续显示关仓。倒计时是浏览器展示逻辑，实际购买权限和开售时间仍以销售平台为准。

目前没有填写真实开仓时间。手机倾斜感应需要兼容浏览器与授权，已提供轻拖回退；仍建议上线后在真实 iOS、Android 设备各验收一次。
