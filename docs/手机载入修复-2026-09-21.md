# 手机序章载入修复

这是针对代码中“必须缓冲满 12 秒才调用播放”的兼容性风险的修复，尚未在用户出问题的实际手机上复现或验证，因此不能断言唯一原因。

- 正常设备继续原有分段缓冲。
- 等待 4 秒仍未达到预载门槛，则主动下载现有约 4.66 MB 媒体，使用本地 blob 播放，解除“未播放不缓冲、未缓冲不播放”的等待循环。备用模式要等待整个文件下载，属于兼容性兜底，不是所有设备的首选模式。
- 装饰题字或伴随海报加载失败不再阻止视频；视频仍能保留最后一帧。
- 浏览器拒绝静音自动播放时显示轻量的播放按钮，可点击启动。保留超时重试和跳过。
- 不修改视频、音乐、购买网址和接口，更新后原版媒体文件仍需存在。

部署时请保留现有 CSP，并确保含 `media-src 'self' blob:`。Vercel 需要在当前 vercel.json/平台安全头中合并该指令，不应替换整个策略，尤其不能删除 CloudBase connect-src。

本地类型检查/构建及桌面 Edge 移动尺寸回归测试。另模拟预载缓冲永远为零、题字加载失败、首次自动播放被拒绝，验证备用下载后点击可播放。模拟测试不等于 iPhone/微信真机测试；仍需用户部署后回测。
